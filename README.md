# Web Watcher

Personal technology change monitoring and research system.

## Phase 2 — Foundation

This repository currently contains only the minimal project foundation.

Included:

- Python 3.11 project metadata
- Minimal package entry point
- Minimal pytest test
- Basic data/log/report directories
- Local Git repository

Not included yet:

- GitHub API
- News fetching
- Web fetching
- AI judgment
- Telegram notification
- Browser automation
- Investigation
- Cron

The project is intentionally isolated from the production AI Radar system.
