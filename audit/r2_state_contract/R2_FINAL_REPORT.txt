Fetch Contract 最终设计
-----------------------
1. FetchStatus 枚举定义了 7 种状态:
   - SUCCESS
   - NOT_MODIFIED
   - HTTP_ERROR
   - RATE_LIMITED
   - TIMEOUT
   - NETWORK_ERROR
   - INVALID_RESPONSE

2. FetchResult 为单一权威类，定义于 src/web_watcher/fetch.py

3. SmartFetcher.fetch() 返回统一 FetchResult

4. FetchResult.success 为 derived property:
   - SUCCESS -> True
   - NOT_MODIFIED -> False
   - 其他 -> False

5. FetchResult.is_304 为 derived property:
   - status == FetchStatus.NOT_MODIFIED

Extraction Contract 最终设计
----------------------------
1. ExtractionStatus 定义了 5 种状态:
   - FOUND
   - SELECTOR_NOT_FOUND
   - EMPTY_AFTER_TRANSFORM
   - MULTIPLE_MATCH
   - TRANSFORM_ERROR

2. MULTIPLE_MATCH 实现:
   - CSS/XPath 选择器匹配 >1 个元素时返回 MULTIPLE_MATCH
   - 不自动取第一个元素
   - 不生成 Signal
   - 保留 match_count

3. SELECTOR_NOT_FOUND 不会产生 false positive

Signal Safety Contract
-----------------------
只有 SUCCESS + FOUND + changed 才能生成 Signal。
其他所有状态均 STOP / NO SIGNAL。

NOT_MODIFIED 不生成新的变化 Signal。
