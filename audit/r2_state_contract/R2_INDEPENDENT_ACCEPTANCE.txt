12. MULTIPLE_MATCH verification
--------------------------------
检查 src/web_watcher/dom_extractor.py:
```python
elements = soup.select(config.selector)
meta["match_count"] = len(elements)

if not elements:
    return ExtractionResult(
        status=ExtractionStatus.SELECTOR_NOT_FOUND,
        ...
    )

raw_text = elements[0].get_text()
return cls._apply_transforms(raw_text, config, meta)
```

发现：
 - 当 elements 数量 > 1 时，代码静默取 elements[0]
 - 永不返回 ExtractionStatus.MULTIPLE_MATCH
 - 无任何测试覆盖多个匹配元素的场景

R2 contract 要求：
 "禁止静默吞掉 multiple matches"
 "如果 selector 得到 >1 matches -> MULTIPLE_MATCH"
 "不能：取第一个"

当前代码违反上述要求。

结论：G7 FAIL - MULTIPLE_MATCH 未实现，存在静默截断
